# Datascene Investor Deck Visual Brief

Date: 2026-06-06

Purpose: visual direction for the selected-investor Datascene presentation. The deck should be calm, credible, and concrete. It should show what Datascene already has, where it is heading, and what support is needed, without sounding like a generic AI pitch deck.

## Visual Rule

Datascene is about traceable audiovisual knowledge.

The visual language should therefore feel:

- institutional,
- research-led,
- source-linked,
- calm,
- precise,
- human-confirmed,
- operational rather than speculative.

Avoid generic AI gradients, glossy stock icons, neon palettes, purple-heavy futurism, and decorative technology imagery.

## Datascene.eu Palette

Use the website palette as the deck base.

```text
Deep navy:      #12354A
Dark navy:      #0B2233
Off-white:      #F5F7F8
Primary text:   #244056
Muted text:     #647789
Teal accent:    #2F8F8C
Copper accent:  #B66F3D
Border gray:    #E2E8EC
White:          #FFFFFF
```

## Use Of Copper

Copper gives the deck personality and should be used deliberately.

Use copper for:

- heading rules,
- evidence markers,
- proof points,
- timestamp anchors,
- source-link highlights,
- small bullets in light cards,
- diagram nodes that indicate human confirmation or evidential authority.

Do not use copper as a large background color. It should act like a precise institutional accent, not a dominant theme.

## Typography

Use a clean sans-serif typeface. The website reads like a restrained modern sans-serif, so use one of:

- Inter,
- IBM Plex Sans,
- Aptos,
- Helvetica Neue,
- Arial as a fallback.

Suggested hierarchy:

- Slide title: 34-44 pt
- Section heading: 20-26 pt
- Body: 15-18 pt
- Captions / callouts: 11-13 pt

Keep capitalization natural. Avoid unnecessary title case.

## Layout System

Use two slide modes.

### Dark platform slides

Use for slides about Datascene itself, traceability, platform direction, and closing.

- Background: deep navy `#12354A`
- Text: white `#FFFFFF`
- Muted text: pale blue-gray
- Accent: teal for active Datascene nodes
- Accent: copper for evidence/proof anchors

### Light institutional slides

Use for customer segments, institutional use, needs, and concrete tables.

- Background: off-white `#F5F7F8`
- Text: primary blue-gray `#244056`
- Cards: white with soft border `#E2E8EC`
- Accent: copper vertical heading rule
- Accent: teal for Datascene or action nodes

## Slide 1: Datascene

### Purpose

Introduce the company, main value claim, and team.

### Visual treatment

Dark navy title slide.

Left / center:

```text
Datascene
Turning audiovisual material into traceable knowledge
```

Supporting line:

```text
Datascene makes audiovisual material searchable, analyzable, and reusable without losing the path back to the original evidence.
```

Team row at bottom:

- small circular or square-cropped photos,
- name,
- role,
- email,
- no decorative frames.

Use a small copper line or dot before "traceable knowledge" to give the slide a quiet signature.

## Slide 2: What Datascene is

### Purpose

Explain the basic proposition clearly.

### Visual treatment

Light slide.

Use a simple horizontal flow:

```text
Audiovisual material -> multimodal analysis -> source-linked knowledge
```

Design:

- material node in blue-gray,
- Datascene analysis node in teal,
- source-linked knowledge node with a copper evidence marker.

Keep the text short. This slide should feel like orientation, not persuasion.

## Slide 3: What we have already solved

### Purpose

Show that Datascene already delivers a working evidence workspace.

### Visual treatment

Dark platform slide.

Use a real VAA1 screenshot as the main visual, preferably showing:

- source video,
- transcript panel,
- timeline or timestamp,
- annotation/evidence panels.

Overlay four callouts:

```text
Source video
Transcript and timing
Evidence constellation
Human-confirmed knowledge
```

Callout style:

- thin white or muted blue-gray lines,
- teal callout dot for Datascene workspace areas,
- copper callout dot for confirmed evidence / timestamp authority.

Main text:

```text
Datascene brings video, transcript, metadata, annotation, and interpretation into one source-linked environment.
```

Key point:

```text
Datascene already delivers multimodal analysis without hallucinating away from the source.
```

## Slide 4: What Datascene delivers

Light slide with a five-segment table.

Segments:

- archives and memory institutions,
- research and universities,
- creative industries,
- public governance organizations,
- strategic enterprises.

Use the table sparingly. Each row should have one concise "current gap" and one concise "Datascene delivers" statement.

```text
EU-level disinformation work | foreign ministry media-sphere analysis | enterprise strategic information operations
```

- video search engine,
