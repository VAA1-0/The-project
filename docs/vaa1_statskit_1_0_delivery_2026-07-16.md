# Datascene/VAA1 StatsKit 1.0 delivery

Date: 2026-07-16

## Version boundary

StatsKit 1.0 is the first bounded, configurable Datascene statistical workbench. It keeps measured results, user-authored source evidence, governed interpretive readings, and not-yet-operational taxonomy targets visible without presenting them as the same kind of fact.

> **Operationalization disclaimer:** The complete attribute-category taxonomy is exposed in StatsKit 1.0 for scientific visibility, configuration, gap analysis, and future delivery planning. The attribute categories have not yet been operationalized category by category. A visible category or atomic attribute does not establish that Datascene currently has a runtime producer, persisted measurement artifact, executable statistical method, Master Schema projection, or source-traceable result for it. Only rows backed by an identified loaded source layer and an actual computed or governed artifact should be treated as operating StatsKit results. Partial, contracted, nominal, experimental, missing, target-only, profile-pending, and `not computed` rows describe readiness or intended scope rather than measured findings.

The 1.0 surface includes:

- the complete 47-category empirical taxonomy with atomic readiness rows and thematic filtering;
- concise descriptive rows for Master Schema, Scene Cards, shot boundaries, source annotations, and multimodal evidence;
- explicit POS and Quant rows rather than hiding those layers under generic topic or action totals;
- explicit governed-reading counts for Aristotle, Freytag, Campbell, Frye, and Booker;
- explicit rows for Performed agency / Shakespearean, Narrative function / Proppian, Symbolic shadow / Jungian / Mythic, Actant relation / Greimasian, and Motive scene / Burkean / Dramatistic;
- values, virtues, vices, motives, and themes as visible atomic interpretive attributes;
- inline row-level evidence inspection that preserves the StatsKit workspace and seeks timed records on the existing video surface;
- calm `not computed` states when a required governed artifact has not been persisted.

The 1.0 layout gives the Stats workbench the first full-width disclosure. Visualization follows as a separate full-width disclosure instead of permanently consuming a right-hand column. Relevance, Significance, comparison, and metadata/governance surfaces follow as secondary work. Disclosure headings use one restrained sentence-case typographic treatment throughout the panel.

## Scientific boundary

An available framework is not itself a result. Plot-lens statistics count persisted `narrative_lens_reading` records. Framework-specific character and agency rows count only records that explicitly name the framework. A button, vocabulary term, or heuristic UI suggestion does not become a measurement. Missing framework-explicit outputs therefore remain `not computed` until a source-linked reading artifact exists.

Source annotations are analyst-authored evidence. StatsKit exposes them separately, preserves their Source Media route, and does not downgrade them to detector candidates. POS and Quant rows consume their saved analysis artifacts and retain their own panel routes.

StatsKit keeps evidence inspection local to the workbench. Selecting a row opens its evidence layer, required layer, data note, record count, and available record-level anchors immediately beneath that row. Timed anchors seek the already open video; untimed records remain inspectable in place. Cross-panel navigation is not required for ordinary evidence review.

The inline evidence disclosure closes either by selecting the same row again or by using its quiet `Close` control. A restored StatsKit panel recovers the most recently selected analysis from the shared video-selection event state, preventing a mounted panel with an already open source from silently presenting zero linked records under `no analysis`.

Dense evidence disclosures paginate locally in groups of 12. The disclosure reports the visible record range and total, provides `Previous` and `Next` controls with the current page position, and resets to the first page when the analyst selects another statistic, analysis, family, or taxonomy theme. Pagination does not change the selected source or leave StatsKit.

Live Visual cues Color regime remains an immediate analyst aid for the selected saved analysis. Because no persisted `spatial_tone_scan` exists, StatsKit reports color as `not computed`; persisted OpenCV color measurement remains a later configuration update.
