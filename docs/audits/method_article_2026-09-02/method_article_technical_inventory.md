# Datascene technical inventory for a method article

Audit date: 2026-09-02. Scope: repository implementation, tests, runtime manifests, and associated design/bug documentation. A status describes the strongest repository evidence, not product intent. Confidence concerns the classification, not scientific validity.

## System boundary and units of analysis

Datascene is a local, researcher-facing multimodal video-analysis system. FastAPI exposes ingestion, analysis, correction, projection, retrieval, statistical, and publication services; a Next.js/React workbench presents a persistent Video panel and domain “leaf” panels. Runtime storage is file-backed rather than a transactional database (`api_server.py`, FastAPI initialization, lines 241–286; `src/frontend/components/LayoutHost.tsx`, default layout, lines 189–287).

The principal units are: source-media record; source clock; sampled frame; time interval; bounding box/ROI; transcript segment and word; audio/speaker turn; scene and scene card; detected object or expression; Narrative Agent occurrence and Digital Twin; evidence item; claim; correction/decision; projected state; analysis/corpus publication. Their common join is intended to be source identity plus source-relative time; spatial evidence additionally carries normalized or pixel coordinates (`src/backend/analysis/timestamp_schema.py`, `MediaLocator` and `Anchor`, lines 42–95; `src/backend/analysis/source_clock_authority.py`, normalization and overlap, lines 27–99).

## End-to-end lifecycle

1. FFmpeg probes media and extracts audio; Whisper and visual samplers produce timed raw evidence.
2. The source-clock layer normalizes source-relative time and records uncertainty/authority.
3. Raw results and manual annotations are persisted in analysis artifacts and compatibility sidecars.
4. Analyst actions enter the decision ledger; projected state resolves precedence as decision over manual over raw.
5. Dependency invalidation and the live bus refresh affected leaf panels, scene cards, meaning layers, Narrative Agent views and searches.
6. Statistical and interpretive modules consume persisted, time-aligned layers.
7. Governed reporting admits claims only with evidence/traceback; publication packages preserve checksums and source references.

The strongest tested property is governance of data movement. The least supported property is the empirical accuracy of the automated deductions.

## Verification performed for this audit

The selected backend contract run completed with **135 passed tests and 8 passed subtests** across clock/timing, ledger, projected state, proliferation, recovery/hydration, reporting, statistics, scene cards, Narrative Agents, diarization and prosody. The frontend Node contract suite was also executed on 2026-09-02 and failed: among the visible failures were native-statistical wording, immediate canonical bbox installation, and runtime-load governance. Therefore frontend-wide claims are classified below “adequately tested,” irrespective of the many passing UI contracts.
